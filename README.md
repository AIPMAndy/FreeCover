# FreeCover

免费、开源、无需登录的中文社交媒体封面制作工具。支持浏览器本地编辑、不同平台尺寸与无水印 PNG 导出。

- 官网： https://aipmandy.github.io/FreeCover/
- 编辑器： https://aipmandy.github.io/FreeCover/editor.html
- 作者： [AIPMAndy](https://github.com/AIPMAndy)

## 发布状态

网站正在通过 GitHub Pages 发布；首次启用 GitHub Pages 可能需要仓库管理员在 Settings → Pages 确认发布来源为 GitHub Actions。

## 隐私

图片在浏览器本地处理，不需要注册。请勿上传敏感资料到不信任的第三方服务。
